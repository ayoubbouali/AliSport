# Gym Manager — interface Angular

Voir le [README principal](../README.md).

- `npm start` : serveur de développement sur http://localhost:4200 (API redirigée vers le port 8090) ;
- `npx ng build` : build de production, écrit dans `../backend/src/main/resources/static` ;
- `npx ng test --watch=false` : tests unitaires (Vitest).
